# Security Policy

Please report vulnerabilities **privately** through GitHub:
**Security → Report a vulnerability** on <https://github.com/fintechcoding/transfercli/security/advisories/new>.
Do not open public issues for security problems.

Supported versions: the latest release. Security fixes are published as a new release with an entry in
[CHANGELOG.md](CHANGELOG.md).

Problems in transfer.sh itself should also be reported upstream: <https://github.com/dutchcoders/transfer.sh>.
How TransferCLI is hardened is described in [docs/security.md](docs/security.md).
