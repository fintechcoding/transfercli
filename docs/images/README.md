# Screenshots

Place the following PNG screenshots here:

- `dashboard.png` — Admin panel home with stats cards and charts
- `files.png` — File list with search or sort active
- `preview.png` — Preview modal open (image or PDF)
- `settings.png` — Global settings page

Recommended size: 1400px wide, PNG, compressed (e.g. `oxipng` or `tinypng`).
